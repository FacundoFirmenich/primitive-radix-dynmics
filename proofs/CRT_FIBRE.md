# Universal CRT fibre for a fixed primitive tuple

Fix reduced states (x_i=p_i/q_i), prescribed target maps (	au,sigma) and exact defects (g_i,h_i). The (T)-edge equations are equivalent to linear congruences
[
B p_iequiv g_i p_{	au(i)}pmod{q_i}
]
together with (gcd(B,q_i)=g_i). Conjugating by (Phi), with (c_i=q_i-p_i), the (S)-edges give
[
B c_iequiv h_i c_{sigma(i)}pmod{p_i},
]
with (gcd(B,p_i)=h_i).

Because primitive coordinates are invertible modulo their complementary coordinate, each local edge prescribes one residue class. The generalized CRT says the full system is either incompatible or defines exactly one residue class modulo the least common multiple of all local moduli. Exact gcd conditions are checked separately and are constant on that progression when compatible.

Thus the base fibre of a fixed primitive tuple is empty or one complete arithmetic progression.
