# Visual/graphical abstract strategy

A visual abstract is not universally expected in pure mathematics, so it should be treated as an optional communication artifact rather than a substitute for the textual abstract.

The repository nevertheless generates `graphical_abstract.*` because the paper has an unusually visual theorem arc:

1. rational state `p/q`;
2. primitive lattice ray;
3. branch matrix + removed content/gcd;
4. rigidity for cardinalities 2–4;
5. exact first breakdown at cardinality 5.

Recommended uses:

- repository landing page;
- social/preprint announcement;
- optional Figure 1 if the target journal layout benefits;
- graphical abstract only where the submission system explicitly supports it.

The generated asset contains no claims beyond the frozen theorem package.
