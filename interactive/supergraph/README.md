# RGΦ-I epistemic supergraph — source-bound projection

The interactive graph indexes the public proof and evidence records. Regenerate it with make graph.

Imported practices from CRISPR Observability:
- typed node/edge roles;
- explicit AND gates;
- revision tests;
- guided reading separated from proof dependency;
- commit-specific source bindings;
- NOT_CLAIMED and adverse outcomes preserved;
- graph geometry never interpreted as evidential strength.

The supergraph introduces no new theorem and does not substitute for proof or external review.
