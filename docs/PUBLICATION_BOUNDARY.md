# Publication boundary

## Embargoed from this repository before arXiv

- article LaTeX source;
- article PDF;
- supplementary-manuscript LaTeX source;
- supplementary-manuscript PDF;
- prose drafts that substantially disclose the unpublished article.

## Allowed

- exact certificates already required to audit the mathematical result;
- verification software;
- machine-readable claim/dependency ledgers;
- reproducible mathematical figures without article prose;
- metadata with a forthcoming article title;
- interactive epistemic graph;
- literature audit;
- release/Zenodo preparation documents.

This boundary is a publication-strategy decision, not a statement that GitHub disclosure necessarily destroys mathematical novelty. The owner controls the embargo transition.
