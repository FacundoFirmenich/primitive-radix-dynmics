# Finiteness of defect-decorated types at fixed cardinality

A type on (n) states consists of two endomaps (	au,sigma) and exact local defects (g_i,h_i).

There are finitely many pairs of endomaps on an (n)-element set. Every strict edge lies on a simple cycle of length at most (n). The cycle budget gives, for each defect (d) on such a cycle,
[
d<2^{lfloor n/2floor}.
]
Hence only finitely many defect labels are possible at fixed (n).

Therefore fixed cardinality decomposes into finitely many abstract defect-decorated types, independently of the base (B). Arithmetic realizability of those types is a separate problem and is not claimed to be classified here.

Supports C013.
